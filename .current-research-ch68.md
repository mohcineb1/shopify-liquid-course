# Research notes — ch-68 Brief & Architecture

Verified 2026-08-15.

Shopify Help states theme customizations per market are available only on Advanced or Plus plans. Store-default settings apply unless market/submarket settings override them; customization inheritance can reach five submarket levels and a theme can have customizations for up to 250 markets. Source: https://help.shopify.com/en/manual/online-store/themes/customizing-themes-for-markets

Shopify dynamic sources connect section/block settings to compatible resource attributes, metafields and metaobjects. They are unavailable for general theme settings. Available data depends on template resource context, setting context, compatible storefront-visible metaobjects and market-specific metafields/metaobjects. Shopify documents dynamic-source limits, including 100 in a JSON template and 50 in a static section or a single setting. Source: https://shopify.dev/docs/storefronts/themes/architecture/settings/dynamic-sources

Shopify performance guidance says basic commerce functionality should work without JavaScript; JavaScript should be progressive enhancement. It recommends a minified JavaScript bundle of 16 KB or less, IIFE scoping for injected scripts, sparing resource hints, responsive images, and no lazy loading of above-the-fold content. Theme Store acceptance requires a minimum average Lighthouse performance score of 60 over homepage/product/collection benchmark tests. Source: https://shopify.dev/docs/storefronts/themes/best-practices/performance

Shopify accessibility guidance focuses on keyboard-operable controls, visible focus, linear DOM focus order, correct page language/skip link/heading hierarchy, form labels/errors, dynamic announcements, accessible modal focus management, and 44 by 44 pixel primary touch targets. Its guidance is not a complete accessibility guarantee. Source: https://shopify.dev/docs/storefronts/themes/best-practices/accessibility
