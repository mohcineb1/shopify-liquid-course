# Research notes — ch-66

- Salesforce official SCAPI documentation retrieved 2026-08-14 states OCAPI is deprecated as of April 2026 and customers should migrate to SCAPI for continued support/security/new features; new implementations must use SCAPI according to that page. SCAPI is RESTful/headless-first; exact SFRA/ISML/cartridge/custom-controller migration design must be `[VERIFY]` against source implementation. Source: https://developer.salesforce.com/docs/commerce/commerce-api/guide/why-use-scapi.html
- Shopify Ajax API is for Shopify-hosted themes only, provides unauthenticated lightweight REST endpoints for theme interactions, reads cart/some product data and updates current-session cart; not usable by custom storefronts, cannot read customer/order or update store data; locale-aware root is `window.Shopify.routes.root`. Source: https://shopify.dev/docs/api/ajax
- Storefront API is GraphQL foundation for custom storefronts; supplies products/collections/cart/contextual pricing; tokenless access covers essentials incl products, collections, selling plans/search/pages/blogs/articles/cart read/write; token-based access required for metafields/metaobjects/menu/customers. Private token must remain server-side. Source: https://shopify.dev/docs/storefronts/headless/building-with-the-storefront-api
- Shopify data modeling doc: metafields add attributes to built-in resources; metaobjects define custom entities. Reference types model relationships; do not store handles/IDs as plain text relationships. Liquid themes can access data irrespective of Storefront API public-read setting; controls must be `[VERIFY]` in store/app context. Source: https://shopify.dev/docs/apps/build/metaobjects/data-modeling-with-metafields-and-metaobjects
