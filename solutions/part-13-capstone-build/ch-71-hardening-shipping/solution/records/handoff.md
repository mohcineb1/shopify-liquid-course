# Handoff and training — candidate

| Role | Receives | Must not assume |
| --- | --- | --- |
| Merchant/editor | Approved settings, empty states, content escalation | That every setting/data source is safe everywhere |
| Developer | Candidate version, structure/data boundaries, evidence workflow | Store configuration or production access |
| Support/operations | Known risks, incident fields, escalation/rollback references | Analytics/monitoring permissions |
| Release approver | Matrix, exceptions, rollback artifact, decision record | That evidence has already been run |

Training tasks: configure approved copy; identify blank structured content; preview nominated route/market `[VERIFY]`; report revision/route/state/device/steps; find escalation and rollback evidence.
