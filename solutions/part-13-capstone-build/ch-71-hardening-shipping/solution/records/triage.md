# Triage — candidate template

| Field | Required information |
| --- | --- |
| Finding | Clear observed problem, not a score summary |
| Scope | Revision, route/state, market/locale, device/assistive technology, fixture |
| Evidence | Raw output, steps, timestamp and reproduction result |
| Decision | Blocker, configuration defect, false positive, exception or improvement |
| Ownership | Resolver, approver where relevant, due date and retest owner |
| Exception | Risk, compensating control, expiry and reopening event `[VERIFY]` |

Do not close a cross-cutting finding until affected route-state evidence is retested.
