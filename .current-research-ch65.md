# Research notes — ch-65 Dawn vs Horizon

Verified 2026-08-14 from Shopify official sources.

- Shopify Help labels Vintage as original architecture (sectioned/non-sectioned); Shopify free Vintage themes receive security fixes only. OS 2.0 supports sections on all pages and dynamic sources. Themes supporting Theme Blocks, including Horizon family themes, are the latest architecture version, support all OS 2.0 capabilities plus advanced Theme Block customization. Architecture version varies by draft theme and availability of settings differs by theme. Source: https://help.shopify.com/en/manual/online-store/themes/managing-themes/versions
- Shopify architecture: JSON templates are wrappers for sections; Liquid templates contain code. Theme components include layout, template, layout section groups, template sections, blocks and snippets. Standard theme directories include blocks, config, layout, locales, sections, snippets and templates. Source: https://shopify.dev/docs/storefronts/themes/architecture
- Theme Blocks are root `/blocks/*.liquid` reusable modules; section-defined blocks are local to a section. Theme Blocks can nest. They receive `block`, their rendering `section`, and global objects, but cannot access outer variables or accept variables like snippets. A section chooses local section blocks or Theme Blocks—not both. Theme Block parents render `{% content_for 'blocks' %}` and use schema `{"type":"@theme"}`; `@app` can be included where supported. Source: https://shopify.dev/docs/storefronts/themes/architecture/blocks/theme-blocks/quick-start
- Horizon’s exact repository/component/Shadow DOM behavior, installed theme version, app integration compatibility, DOM/CSS assumptions and migration safety are all `[VERIFY]` in chapter content. Treat changed DOM, Web Component boundary and Shadow DOM as risks to inventory/test rather than generic source facts unless verified against selected Horizon version.
